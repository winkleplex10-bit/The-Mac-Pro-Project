Changes since the 2026-10-29 sync. Only the base board (boards/base-v3) moved today; the CPU board (v4), SSD board A, I/O, firmware, power supply and mechanical files are unchanged.

## Base board (v3)
- **PS_ON interlock parts removed from the PCB.** Q7, Q8, R12, R15 and R55 (already removed from the schematic with Aidan's approval on 10-29) are now gone from the layout too, along with the copper on their dead nets (PSON_DRV, PSU_PWR_OK_M, ILK_B). The schematic and PCB match again on this.
- **ERC rerun (10-29, 10:13 PM ET): 0 errors, 142 warnings**, down from 330 warnings at the 11:50 AM run. The remaining warnings are mostly unconnected global labels waiting on the GPU face pinout and the CPU board J1 power pins. Report: `boards/base-v3/kicad/erc_report_20261029_2213.txt`.
- **Autorouting of non-Gen5 nets is still in progress.** The latest trial run stopped with about 276 nets unrouted and was not applied to the board, so the committed PCB is the post-PS_ON-removal layout with the earlier routing. Not fab-ready.
