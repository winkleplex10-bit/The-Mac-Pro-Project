# MacPro6,2 — Design Status (2026-10-28)

Baseline spec (locked 2026-10-25, AM5 only) is unchanged; see [STATUS-2026-10-26.md](STATUS-2026-10-26.md).

## Decisions from Aidan (2026-10-28)
- GPU path is on hold. The GPU face stays a generic placeholder (Gen5 x16); CPU board J1 is unchanged.
- Gen5 links (GPU x16, SSD board A x4 + x4) use public-datasheet TI redrivers on the base board, with a retimer fallback footprint (DNP).
- I/O board: keep the Parade PS8838 on C1/C2; ASM4242 USB4 host stays, PS8830 retimers held as fallback footprints pending simulation. MEG-Array grid unchanged.
- Storage: SSD board A only (two native CPU x4 Gen5 ports, no switch). SSD board B is on hold.
- Firmware: Ryzen 7000/9000 via a licensed board maker (ODM) for AGESA; openSIL/8000G path not pursued.
- CPU board VRM controller: TI TPS53685 (public datasheet, SVI3) replaces NDA-gated controllers; power-stage compatibility still to check.

## Base board (backplane v3) — draft, not fabbed
- Redrivers placed: DS320PR1601 (GPU x16) and two DS320PR810 (SSD x8 = 2 × x4). Retimer fallback is a separate DNP footprint; pin compatibility is not assumed.
- Segment length estimates: `am5/gen5_redriver_segment_lengths_2026-10-28.csv`. Rule: SSD-board Gen5 runs ≤ 60 mm connector to M.2.
- Details: `am5/interboard-bandwidth-map.md` (rev 7b).
