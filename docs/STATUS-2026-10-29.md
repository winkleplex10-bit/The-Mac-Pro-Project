# MacPro6,2 status, 2026-10-29

Daily sync of the team's design state. Board files and docs live in their own folders under `boards/`.

## Decisions from Aidan today
- **CPU board J1 (224-contact card edge) is pinned**: `boards/cpu-am5/kicad/docs/cpulink_224_pinout_am5_v4_PINNED.csv` (12x P12V on A/B102-107, 80 GND). The base board J1 pads were checked against it pin by pin.
- **H2 mounting hole** on the CPU board is a 5.0 x 6.0 mm oval slot along the H1-H2 axis.
- **OpenCore boot drive dropped**: no boot NVMe on the CPU board or the base board. Boot now comes from the SSD board (2x Gen5 x4).
- **3V3_SB standby regulator** on the CPU board is sized for 2 A continuous; it also feeds the base and I/O boards through J1. Part not yet chosen.
- **No NDA parts on the base board**: the PT5161L retimer placeholder was removed. Gen5 links use the public TI redrivers (DS320PR1601 for the GPU x16, 2x DS320PR810 for the SSD x8).
- **Base board connectors**: J2 (PSU Micro-Fit) and J6 (I/O link) deleted, J6 functions folded into the J13 I/O MEG-Array; J14 (MCIO-124, base end of CPU board J3) placed on the top side.
- **SSD board** gets its own 12 V input from the PSU on the stock second-GPU feed connector, so 12 V no longer runs over J12. Its base link is a 300-pin MEG-Array (MCIO retired for this board).
- **I/O board** stays a 4 mm MEG-Array stack; 12 V feed is still being settled (the provisional standoffs were withdrawn in favour of feeding it from the PSU like stock; see the I/O plan and the power proposal).
- **PS_ON interlock chain** (Q7, Q8, R12, R15, R55) removed from the base schematic (approved); the PCB still needs the matching removal.
